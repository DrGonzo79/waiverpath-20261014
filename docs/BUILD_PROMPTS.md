# Phased build prompts

1. **Policy contract:** Create a versioned rule registry sourced only to current SSA material. Add effective dates, supersession, reviewer sign-off, stale-rule blocking, and contract tests against the demo calculator.
2. **Observed concierge:** Build a reviewer console for redacted intakes, reason codes, escalation, time tracking, and price-accept capture. Persist no raw documents yet.
3. **Secure evidence:** After threat modeling, add explicit consent, client-side redaction, encrypted object storage, tenant isolation, access-purpose logs, retention timers, and deletion receipts.
4. **Human-reviewed assistance:** Generate cited draft evidence maps. Require qualified approval for every conclusion; measure overrides and near-misses. Do not submit forms.
5. **Authorized workflow:** Only after counsel and representation credentials are resolved, add signed scope, fee-approval checks, portal actions, partner routing, and auditable submission receipts.
